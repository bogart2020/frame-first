# The six stages

Attention -> Relevance -> Retention -> Reward -> Sharing -> Relationship.
A post fails if any single stage breaks, however good the rest is.

## To write here
- What each stage requires, as a checkable condition
- Emotional payload taxonomy: amusement, recognition, curiosity, awe, surprise, nostalgia, anger/injustice, hope, sadness. One dominant driver per piece. Emotion is not the same as positivity
- Sharing as identity: people send things that say something about themselves
- Retention vs. satisfaction — a viewer can watch to the end and still feel robbed
- The four value types: utility, entertainment, identity, connection. Strong posts combine two or more
